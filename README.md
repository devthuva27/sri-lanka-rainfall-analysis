# Sri Lanka Rainfall Analysis

## Project Overview
This project analyzes historical weather data from Sri Lanka to understand rainfall patterns and identify extreme rainfall events that may indicate potential flood risk.

## Dataset
- Source: Kaggle – Sri Lanka Weather Dataset
- Key variables used: date, location, rainfall

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas, Matplotlib

## Key Insights
- Rainfall shows strong seasonal patterns
- Certain months receive significantly higher rainfall
- Extreme rainfall events are rare but concentrated in specific periods
